# 作数｜专注、记录、复盘

让每一天都作数。知乎黑客松 2026 校园新锐季，本地优先 Mobile-first PWA，支持知乎检索与模型回顾。

## 本地启动

需要 Node.js 20.9+、npm。

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

打开 http://localhost:3000 。本次工作区已配置 `.env.local`。

生产模式（验证 PWA）：

```powershell
npm run build
npm run start -- --hostname 0.0.0.0
```

普通专注固定为小番茄 25 分钟、大番茄 52 分钟，多颗之间休息 5 分钟。首次使用教程中的第一颗番茄单独缩短为 3 秒；教程完成或跳过后立即恢复正常时长，教程足迹仍按一颗标准 25 分钟小番茄记录。

## 演示路线

1. 全新且没有真实记录的浏览器会进入一次完整教程：右滑完成、长按恢复、加入阅读待办、完成 3 秒教程番茄、把番茄拖到待办、写示例日记并生成固定回顾、星标、把具体方法加入明日，再查看足迹和果园。遮罩只开放当前目标；刷新、切后台或关闭后从当前步骤继续。退出引导会永久跳过且不留下教程记录。
2. 完成教程后，阅读任务、标准 25 分钟模拟番茄、示例日记和固定回顾写入首次打开日的前一天；“开始读书前，先把手机放到够不到的地方静音，先读 25 分钟”写入首次打开日的待办。现有十天演示足迹固定平移到首次打开日之前第 11 天至第 2 天，因此时间轴连续，正式使用当天不会被教程过程污染。
3. 开始专注：默认小番茄，也可选择大番茄；可连续种 1–4 颗。倒计时依据持久化的结束时间，刷新、切页后恢复。教程的 3 秒状态不会进入普通专注设置。
4. 专注结束即保存成熟番茄并计入「今日已种」。首页树上最多显示 3 颗，拖到待办圆圈分配，余下库存自动补位；满格继续接收并向左堆叠，后果右侧约四分之一被前果遮挡。每颗唯一 ID，事务分配防止重复计数。
5. 成熟页可回到果树，或继续本轮：多颗模式休息 5 分钟后手动开始下一颗。未分配库存不影响继续专注。关闭页面后重开按持久化结束时间补记，归到专注结束当天。
6. 回顾：输入日记，点击「让今天作数」。普通、开心的一天只回应「今日闪耀瞬间」；只有仍未解决的困惑或负面卡点才检索经验，最多一次日记理解和一次材料匹配。生成期间可以切到今天或足迹，任务会在当前浏览器标签页后台继续，返回回顾页即可看到进度或结果。外部服务失败时仍返回本地回顾，详见 `docs/api.md`。
7. “别人也这样走过”先显示与当天处境相关的摘要，点击卡片底部箭头可在站内展开来源正文；若正文首句已作为摘要展示，展开内容从下一句开始，避免重复。可选登录知乎；命中相关的近期收藏时显示「曾经收藏，今天重看」，有具体方法且用户确实想找下一步时才显示「明天可以试试」。
8. 从第一篇真实日记起按连续七个自然日划分周期；在周期第七天写完日记并点击「让今天作数」后生成「每周回声」，显示在该周期结束日的足迹详情中。演示日记不参与真实周期统计。
9. 点击「加到明天」，回到今天页切换「明天」查看。一份回顾只添加一次；删掉对应任务后可以重新添加。
10. 足迹：按日期查看待办、番茄、日记、每日回顾和每周回声。右上角可清空当前浏览器中的足迹、日记、计划、番茄记录与 Demo 演示；操作前会再次确认。清空历史不会重新触发教程；从空状态恢复演示足迹时仍使用首次打开日期作为锚点，并跳过已有真实记录的日期。未来任务在「明天」中查看，不放入足迹。

## 目录

```text
app/                  App Router 页面、布局、全局样式、manifest
components/tasks/     Today、TaskList（含编辑表单和右滑）
components/focus/     FocusTimer
components/reflection/ 日记编辑与结果卡片
components/layout/    日期上下文、底部导航、PWA 注册
components/mascot/    可替换的原创小芽占位组件
lib/db.ts             Dexie 表、初始化、事务与幂等写入
lib/date.ts           本地日期与跨月/年明日日期
lib/mock-data.ts      集中管理所有 Mock 文案与初始任务
lib/reflect-client.ts POST /api/reflect 客户端适配器
lib/reflect/          需求门控、模型调用、知乎检索与收藏匹配
lib/weekly.ts         七日周期和每周回声降级逻辑
lib/weekly-generation.ts 周期结束日的每周回声生成与持久化
types/index.ts        数据模型和 DailyContext / ReflectionResult
public/               安装图标、基础 Service Worker
```

技术栈：Next.js 16.3.4、React、TypeScript、Tailwind CSS 4、Dexie、dexie-react-hooks、Lucide。使用 React hooks 和一个日期 context，没有大型状态管理。

`requestReflection(context): Promise<ReflectionResult>` 调用 `POST /api/reflect`。后端先理解日记并判断是否真的需要外部经验；需要时并行发出最多两条知乎检索，并在有候选材料时做第二次模型匹配。60 秒内部截止后会降级为本地回顾；EdgeOne Node Functions 外层上限为 90 秒。客户端任务由全局模块持有，不随 Next 页面组件卸载而退出。

## PWA 与数据边界

- 生产模式提供 manifest、192/512 PNG 图标、standalone、Apple 主屏幕元数据和基础离线缓存。
- HTTPS 或 localhost 下可注册 Service Worker。手机通过局域网 HTTP 可访问页面，但安装及部分安全上下文能力需 HTTPS；本机 localhost 可验证。
- 先联网访问需要使用的页面，使对应 JS 资源进入缓存，之后可离线重开已缓存页面。此处是轻量缓存，不承诺未访问页面的离线首次启动。
- 数据保存在当前浏览器、当前来源的 IndexedDB。刷新和正常关闭不会清除；清理站点数据、隐私窗口结束或浏览器清理存储会丢失。不同端口/域名和不同设备不共享。
- 新回顾来源只能绑定知乎搜索或用户授权后的近期收藏；旧记录继续兼容展示。页面先显示开放接口返回的摘要，并在来源包含正文时支持站内展开阅读。星标保存在本地，不是知乎收藏操作。
- 回顾会将当前日记、任务和番茄记录发送到本站服务端，模型接收流程所需上下文，知乎接收必要的检索词；服务端不持久化日记。知乎登录为可选能力，OAuth token 仅保存在加密、HttpOnly 会话 Cookie 中；没有云端日记同步或推送。

### 首页番茄交互更新

首页按预计数量显示空心番茄位；预计数选填，未填写时不显示空心圆。红色番茄只能由完成的专注产生，点击不会新增或取消；可随时拖到另一条待办，移动只改变归属，不改变今日种植总数。超过预计后向前堆叠，后方番茄依次降低 10% 透明度。放下后触发一次 380ms 抖动，拖起时显示摘取动效。编辑页显示已投入颗数。卡片跟随右滑，位移达到阈值后完成；长按已完成卡片约 550ms 恢复。左侧滚动条与卡片圆点一同构成滚动列表。

### 果园

首页果树的枝叶区域和足迹页的「我的果园」入口均进入 `/orchard`。每屏以三排近大远小的果树展示九个连续日期，按各日成熟番茄记录汇总；无记录显示空树，有更早记录时可翻阅更早九天。每棵树最多绘制 10 颗，树下数字始终为完整数量，并与首页「今日已种」一致。

底部导航为悬浮胶囊条，包含今天、回顾、足迹；果园沿用足迹的高亮位置。淡番茄红圆底作为共享指示器，在切换路由时平滑滑到目标图标；三个主标签不播放整页入场动画。足迹时间轴只在初次展示、滚动、尺寸或内容高度变化时重新测量。首页果树在加载、页面滚动和触摸移动时轻摆；果园在加载与翻页后按三排依次摆动，并响应滚动、触摸和桌面指针。触摸监听不阻止浏览器原生滚动，系统开启减少动态效果时关闭这些动画。整页不接管左右滑动，避免与手机浏览器的返回手势冲突。

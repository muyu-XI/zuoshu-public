# 今日待办首次引导

## 目标

当本地用户第一次打开空白的「今日待办」时，用两张与真实任务同风格的示例卡填补首屏，并直接教会右滑完成、长按恢复和预计番茄三个核心概念。引导本身不能进入任务、日记、番茄或足迹数据。

## 方案

引导仅在今日任务为空、且浏览器中不存在 `zuoshu:first-visit-task-guide-v1` 标记时展示。首次展示时立即写入标记，因此页面刷新、日期变化以及「清空历史」都不会再次触发；只有用户主动清除站点浏览器数据后才会重置。当前产品没有账号体系，所以该约束准确地说是“同一浏览器资料只展示一次”，不能跨设备识别同一个人。

第一张卡是纯前端手势练习：向右滑动后切换为长按恢复提示，键盘用户可用空格或回车完成同样切换。第二张卡是可选任务「读一章书，记下一个问题」，点击后才写入一条预计一颗番茄的真实今日任务；真实任务出现后示例立即隐藏。普通的新增任务按钮保持不变。

早期预览曾把「右滑以完成待办」和「长按可以恢复代办」写成真实任务。初始化时执行一次严格迁移：仅在当天同时找到这两个标题、预计数分别为 2 和 1、实际番茄为 0、没有来源与关联专注记录时删除它们，其他用户任务不受影响。

## 验证

- 首次空列表显示两张示例，刷新后不再显示。
- 手势练习不会改变 IndexedDB 中的任务、番茄、日记或足迹。
- 点击读书示例只新增一条真实任务，并隐藏引导。
- 已有真实任务时不展示引导；清空历史不会删除首次展示标记。
- 键盘操作、窄屏布局、深色模式及减少动态效果设置均保持可用。
